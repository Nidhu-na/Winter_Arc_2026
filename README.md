# WINTER ARC ❄️ // 90-DAY OFF-GRID DISCIPLINE PROTOCOL

> *"Winter is not a punishment. It is the forge."*

A self-discipline web app for the 90-day winter season where operators disconnect from dopamine distractions, go off-grid, and rebuild themselves from the bedrock up.

Monk mode meets gamified accountability. Dark, cold, cinematic aesthetic — frosted glass, deep blues, stark snow whites, and ember alerts. Zero corporate wellness fluff.

---

## ⚡ Core Philosophy

- **3–5 Non-Negotiables**: Pick your daily vows. Missing ONE shatters the chain.
- **The Ice Fortress**: Each day completed builds a monolithic ice block in your 90-block citadel. Missed days crack the walls. 90 days = an unbreakable monolith.
- **Streak Protection with Teeth**:
  - **Grace Tokens**: 1 per 30-day block, earned through unbroken consistency, not gifted freely.
  - **No Zero Days Protocol**: If crisis strikes before midnight, execute the mandatory 5-minute minimum to preserve the chain.
- **Proof of Work Ledger**: 1 sentence minimum of raw truth every day. No therapy.
- **The Cold Room**: Solo mode or Squad mode (up to 5 comrades). Real-time status, distress alerts, and war horn calls when someone slips.
- **The Thaw (Day 90 Endgame)**: Full personal recap, crystalline fortress reveal, shareable survival certificate, and ascension to higher difficulty (*Nightmare Arc*, *Permafrost Protocol*).

---

## 🛠️ Tech Stack

- **React 19 + TypeScript + Vite**
- **Tailwind CSS v4** with custom frosted glass, cold glow, and ember keyframes
- **Motion (Framer Motion)** for fluid gestures and animations
- **Lucide Icons**
- **Web Audio API Procedural Synthesizer**: Zero external audio dependencies — synthesized glass shattering, low flame rumbles, sub-bass monolith thuds, and victory fanfare.
- **Canvas-Confetti**
- **Offline-First LocalStorage Persistence**

## 🚀 Deployment

### Local Development
```bash
npm install
npm run dev
```

### Production Build
```bash
npm run build
npm run preview
```

### Vercel / Cloud Run / Netlify
1. Connect your repository to Vercel or your hosting platform.
2. Build command: `npm run build`
3. Output directory: `dist`
4. Node version: 18+ or 20+
